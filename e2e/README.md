# Testes E2E (Maestro)

Requer um dev build instalado em emulador/aparelho e o [Maestro CLI](https://maestro.mobile.dev).

```bash
maestro test e2e/
```

Os fluxos usam os textos em pt-BR; rode com o aparelho em português.
Captura (câmera/sensores) e galeria precisam de aparelho físico e são validadas manualmente
(checklist em `docs/IMPLEMENTACAO.md`).
